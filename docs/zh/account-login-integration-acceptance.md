## 实现范围与参考

参考上游提交 [`7c356e053d39992e4e9e4eda24a940d4d44477e8`](https://github.com/iBUHub/AIStudioToAPI/tree/7c356e053d39992e4e9e4eda24a940d4d44477e8)，核对了 `scripts/auth/saveAuth.js`、仓库内的 `setupAuthBatch.js` 和自动填充说明。上游作者信息为 Ellinav、iBenzene、bbbugg，许可证为 CC BY-NC 4.0；新页面模块保留参考归属，未移植上游整套 CLI 或浏览器启动配置。

本次实现包括：

- AI Studio 同源首次协议容器识别、原生/ARIA 必需复选框、明确确认按钮及其可见文字后备匹配；不勾选邮件订阅。多步处理和无变化重试均有上限。
- 在等待编辑器时检查协议，要求页面稳定至少 1.5 秒；目标连接验证后，在最终会话上下文再次检查协议和实际邮箱。
- 恢复邮箱的旧存储兼容、新增/编辑/清空、凭据版本保护、IPC 传递、去重合并、预览冲突和导入导出。普通投影不返回完整恢复邮箱，Cookie JSON 不包含该字段。
- 旧三列和新四列带表头 CSV、字段别名冲突、BOM、表头空白、密码原样保存和 ZIP 导出。批量 CLI 改用 CSV 解析器，保留引用字段内的换行与空格。
- 已确认 Authenticator 挑战中的单框/六格输入、近过期等待、一次换码、自动提交后的状态复查。
- 根据真实截图补充“控制 API 费用”非阻塞提示的有限处理，只操作明确的关闭按钮，不打开可选支出设置。
- 失败结构摘要仅包含类型和白名单标签，增加协议结果枚举；扫描数量受限，随既有登录历史清理。截图掩盖输入、邮箱以及本次使用的敏感凭据和验证码。

未知授权、Drive 权限、地区限制、密码修改、短信、设备确认、企业 SSO、邮件验证码及图片验证码仍须人工处理。

## 真实账号验收

使用用户授权账号，通过 `scripts/auth/testAccountLogin.js` 的 stdin 输入凭据。所有账号数据库、Cookie 和绑定均放在独立私有临时目录；测试结束删除数据库和 Cookie，不修改生产认证目录。账号、密码、恢复邮箱和密钥不写入本记录。

环境原本没有 Firefox/Camoufox；本次使用临时 Playwright Firefox 148.0.2，保持生产执行器的固定 headless 模式、Google 登录入口和默认交互节奏。因此这次结果代表该测试环境，不代表部署环境的 Camoufox 已单独验收。

| 次序 | 观察与结果                                                                                                             |
| ---- | ---------------------------------------------------------------------------------------------------------------------- |
| 1–2  | 邮箱、密码、TOTP 完成，进入中文首次协议；协议确认未完成，任务失败，无会话提交                                          |
| 3    | 曾得到目标连接和会话提交成功，但未观察到协议处理；用户随后确认协议仍在，此次不计作首次协议验收成功                     |
| 4    | 增加脱敏截图后确认：编辑器在协议后方已经加载，按钮可见文字是“继续”；原可访问名称规则未命中。任务失败，无会话提交       |
| 5    | 修正作用域内可见文字匹配后，协议消失，目标原生连接验证通过；最终上下文复查识别到可选费用提示，任务安全停止，无会话提交 |
| 6    | 加入已确认费用提示规则后，最终上下文协议/身份复查、目标初始化、原生连接和会话提交全部成功                              |

改造期间的成功验收输出：

```json
{
  "attempts": 1,
  "credentialFreeAuth": true,
  "error": null,
  "identityMatched": true,
  "sessionBindingCount": 1,
  "sessionCommitted": true,
  "status": "succeeded",
  "targetInitialized": true,
  "termsVerified": true
}
```

每次测试的队列最多一次尝试；调试时只保留私有目录中的脱敏截图。初次协议的确认已在第 5 次观察到，最终成功任务再次检查提交上下文；没有把第 3 次的编辑器出现或连接结果当作协议完成。
