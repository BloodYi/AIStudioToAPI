# Claw Cloud Run 部署说明（历史入口）

本页面原为上游预构建镜像的云平台教程。本独立维护版本统一采用本地源码构建，原教程不再作为本版本的部署步骤。

请使用 [README 中的 Docker 本地构建说明](../../README.md#快速开始)，或仓库的 [docker-compose.yml](../../docker-compose.yml)。

如需在支持自定义镜像的云平台运行本版本，先本地构建，再将镜像推送到你自己的镜像仓库，并按平台要求配置访问权限、环境变量和持久卷。`aistudio-to-api:local` 是本机镜像标签，云平台无法直接拉取。

需要持久化 `/app/configs/auth` 与 `/app/data`，并设置自己的 API 密钥和控制台密码。平台是否可用及其资源限制，请查看平台当前官方文档。
